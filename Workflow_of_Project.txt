# Process of how to work on this Project 

1 : Env Setup
    - First create a backend folder which have config.py file having pydantic BaseSetting implemented
    - Create a .env file with the Credentials which can be used in the program

2 : Backend Creation
    - create a models folder having db_models.py which have the model for our database first start with user model 
    
    - create a utils folder having __init__.py and auth.py which have all the authentication basic function code
        -> hash_password 
        -> verify_password
        -> create_access_tokens
        -> create_refresh_tokens
        -> decode_tokens
        -> get_current_user

    - Create Router folder in backend and make a Auth.py file in it having below function 
        -> first of all go to models then db_models make pydantic request response schemas like
            - UserCreate :- For Signup 
            - UsageStat  :- For check how much user is using our services
            - UserLogin  :- For Login
            - TokenResponse :- For Response of JWT tokens 
            - UserOut :- for getting user 
        -> now in the Auth.py file make the below App router 
            - /register 
            - /login 
            - /refresh 
            - /me 
        -> now make a rate_limiter file in middleware folder which should be in the backend to set the limit of request given by the user for not overwhelming the app 
        -> Upload this much code to render and see the backend is working or not.
        -> Integrate backend to frontend, fist make frontend folder outside everything and do below steps 
            - make a requirements.txt for frontend with request and streamlit 
            - make a file name api_client.py which can be useful for functions handling the auth only for now 
            - make a app.py file and add signup and login in it.

    - Time to work on the document upload to pinecone, for that first we have to make a vector_store.py in services
      with logic of per-user namespace isolation 
        -> Make a file name vector_store.py having function like below 
            - usert_chunks : For upload and insert the chunks 
            - query : For querying the pinecone db 
            - delete_by_source : For delete the doc using it id 
            - delete_namespace : For deleting the entire namespace 
            - namespace_stats : For get status of current namespace
        -> Make another file for embeddings name it as same as the work embeddings.py having functions like 
            - embed_query : For query embedding
            - embed_documents : For document embedding
            - embed_texts : both above function can call this function to convert into embeddings 
        -> Now add DocumentRecord class in the db_models.py so that we can push the doc on mongo 
        -> also add class StatsOut and class DocumentOut
        -> Now in services make document_processor.py with below functions 
            - _parse_pdf : For parsing PDF file 
            - _parse_docx : For parsing DOCX file 
            - _parse_txt : For parsing TXT file 
            - parse_file : Return raw_text and file_type using the above three functions 
            - ingest_document : Ingesting the document on Pinecone and MongoDB
            - delete_document : delete the document from the Pinecone and MongoDB
        -> Now In router make a file name documents.py having API router and add the paths in it 
            - Add a background function for ingesting the document _background_ingest
            - "/upload" -> upload_document() -> This will upload the document to Pinecone and MongoDB
            - "/" -> list_documents -> Get all the document of this particular user
